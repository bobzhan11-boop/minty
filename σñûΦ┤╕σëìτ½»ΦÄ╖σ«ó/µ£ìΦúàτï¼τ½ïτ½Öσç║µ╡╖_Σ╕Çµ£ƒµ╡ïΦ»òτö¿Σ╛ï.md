## 用例编写说明

- **用例编号规则**: `TC-<模块>-<序号>`，例如 `TC-HOME-001`。
- **优先级**: P0（核心链路，阻塞上线）> P1（重要）> P2（一般）> P3（边缘 / 体验）。
- **类型**: 功能 / 接口 / 兼容 / 性能 / 安全 / SEO。
- 预期结果须可观测、可判定（页面状态、数据库记录、接口返回、埋点事件等）。

## 附录：测试数据与环境约定

- **测试环境**: 独立 staging 环境，数据库与生产隔离。
- **UTM 测试样例**: `?utm_source=test&utm_medium=cpc&utm_campaign=qa`。
- **文件用例**: 合法（5MB JPG、10MB PDF、AI 文件）、非法（25MB 超限、.exe、EICAR 病毒样本）。
- **账号**: 管理员、运营人员、注册普通用户各至少 1 个；越权测试需 A/B 两个普通用户。
- **埋点验证**: 通过浏览器 Network 面板 + GA4 DebugView + `tracking_events` 表三方核对。
- **缺陷分级**: 阻塞（P0 用例失败）/ 严重 / 一般 / 轻微，对应修复时效另行约定。
